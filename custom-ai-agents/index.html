Best after a Starter Session. Together we map one repetitive process and work through a custom Claude agent concept. The offer includes a how-to guide and a check-in after one week.

Agent planning may cover

  • The agent's single intended task and boundaries
  • Instructions and reference information it may need
  • Example inputs and expected outputs

Any implementation beyond the stated consultation needs a separate written scope, access review, and owner approval.
